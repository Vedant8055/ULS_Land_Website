# Transformative Living — Masrul, Nashik

Cinematic, story-driven website for a **concept-stage** nature-centric community vision. This is not a property portal and not a live booking system.

## Start locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The homepage is a scroll-directed cinematic story (GSAP + two conceptual WebGL scenes). Secondary routes remain editorial. Use `?nowebgl=1` to force photographic fallbacks.

```bash
npm run typecheck
npm test
npm run lint
npm run build
npm start
```

## What is real vs demo

- **Real in this build:** multi-page narrative, licensed local photography, bundled 15s silent concept film, interactive day timeline, ecosystem map, material atelier, concept masterplan, rainwater/energy explorers, four-step Private Concierge with validation.
- **Demo only:** enquiry submission. The API acknowledges a well-formed request and explicitly does **not** store or email it.
